# SwiftPCBPanelizer for macOS

EAGLEの`.brd`とKiCadの`.kicad_pcb`を面付けするmacOS用SwiftUIアプリです。

最初は C# の GerberPanelizer のコードを見ながら作ろうとしていましたが、現在は参照せず新しく作成しています。

現在のコードはスイッチサイエンスのPythonスクリプトを参考にしています。
https://github.com/SWITCHSCIENCE/eagle-panelize

これがベースになっていて、kitkit などは見ていません。

EAGLEもKiCADも面付けしようとすると大変だったので、このアプリはChatGPTが作成しました。

## ライセンス

MITライセンスにしました。全文は`LICENSE`ファイルを参照してください。

## ビルドと実行

`SwiftPCBPanelizer.xcodeproj`をXcodeで開き、`SwiftPCBPanelizer`スキームを選択して、**Product > Run**（⌘R）で実行してください。macOS 14以降とXcodeが必要です。

## アプリアイコン

最新のユーザー提供画像の上段右100pxにある、黒と金の単一基板デザインを使用しています。中央の金色ICと明るい連続した内側の外形線を維持し、外側の透過余白を除いて角丸の本体をキャンバスの四辺まで広げています。macOS用の16〜1024ピクセル全10サイズをDebug・Releaseに組み込みました。サイドバーは同梱の`PanelizerArtwork`画像を直接読み込み、起動時にDockにも同じ画像を明示的に設定して、システム側の古いアイコンキャッシュの影響を避けます。透過PNG、サイズ展開スクリプト、40／64／100ピクセルの実寸Dockプレビューについては`Design/AppIcon/README_ja.md`を参照してください。

## 文字サイズ

画面の文字は従来の115%を初期値にしています。メインウィンドウのツールバーにある **文字サイズ** から、100〜160%の範囲で調整できます。スライダーのつまみは初期表示から常に表示され、マウスを重ねたりフォーカスしたりしなくても操作位置が分かります。ネイティブのスライダーは連続的に動き、ドラッグ中もすべてのウィンドウの文字サイズをリアルタイムに反映します。レイアウト更新は最大30回/秒にまとめ、ドラッグ中は1%未満の変化も保持します。離した時に整数の割合を次回起動用に保存し、反映待ちの古い値で確定値が上書きされないようにします。調整画面は固定サイズのネイティブポップオーバーとし、拡大縮小するツールバーではなくウィンドウに紐付け、スライダーや表示位置が再配置で置き換わらない構成にしています。アプリの「設定」でも同じスライダーを使えます。完成プレビューには文字サイズ調整ボタンを設けず、共通の文字サイズ設定を反映します。**標準に戻す（115%）** で初期値に戻せます。

## ソースコードの文字定数

アプリ本体が使用する文字列・文字リテラルは、`Sources/SwiftPCBPanelizer/TextConstants.swift`の変更不可の定数へ集約し、機能別・共通値・解析用の文字に分けています。英語・日本語・ドイツ語とOS言語による選択は維持し、Character型の解析記号やSwiftUIのローカライズキーの型も保持します。

可変部分を含む文は、定数の`TextTemplate`または`LocalizedIntegerTemplate`から生成します。`%@`は順番付きの差し込み位置として扱い、printf処理や再帰的な置換は行いません。通常の%記号や挿入した値はそのまま保持し、既存のprintf形式には従来の書式APIを使います。定数の場所、テンプレートの契約、型の役割を英語・日本語・ドイツ語のコメントで説明しています。ビルド設定ファイルと解析用の入力サンプルは、それぞれに必要な構文を維持します。

## 使い方

1. `.brd`または`.kicad_pcb`を追加するか、ウィンドウにドラッグ＆ドロップします。
2. 1ファイルの場合は、行数と列数を指定して基板を複製します。複数ファイルの場合は、各基板を1枚ずつ同じパネルに配置します。列数で折り返し、行数は自動計算します。行の高さは、その行で最も高い基板に合わせます。
3. 横・縦の基板間隔、外枠の幅、外枠と基板の隙間を設定します。必要に応じてタブ、ミシン目、分割ガイド線、取付穴を追加します。
4. 保存ダイアログで1つの面付けファイルを書き出します。元ファイルは変更しません。

EAGLEの処理はSWITCHSCIENCE/eagle-panelizeの`panelize.py`の構造と設定を参考にしています。Dimensionレイヤー20から基板外形を取得し、`plain`・`elements`・`signals`を複製します。既存のレイヤー102のVカット線を展開し、パネル外形や四隅の取付穴を追加できます。

KiCadでは基板のS式を解析し、`Edge.Cuts`から外形を取得します。基板要素を配置し、複製した要素のUUIDとフットプリントの内部参照名を重複しない値に変更します。パネル外形、分割ガイド線、取付穴を追加できます。プレビューには元の基板外形と、基板・外枠・タブを組み合わせた加工線を表示します。

## パネルの初期設定

新規パネルは次の設定で開始します。長さの単位はすべてmmです。

| 項目 | 初期値 |
| --- | --- |
| 列数 × 行数 | 2 × 2 |
| 横方向 / 縦方向の基板間隔 | 2 / 2 |
| 左右 / 上下の外枠幅 | 10 / 10 |
| 外枠と基板の隙間 / パネル角のR | 2 / 2 |
| 外形線幅 | 0.01 |
| 接続タブ | 有効、幅3、各辺2個 |
| 外枠との接続 / 隣接基板どうしの接続 | 4辺すべて有効 / 有効 |
| 切り取り用ミシン目 | 有効、穴径0.5、穴ピッチ1 |
| 分割ガイド線 | 無効 |
| 四隅の取付穴 | 有効、左右端 / 上下端から3 / 3、ドリル径3.2 |

## 外枠との隙間とタブ

外枠幅は材料として残すレールの幅です。外枠と基板の隙間は、基板配列と外枠の内側との距離を指定する別の設定です。パネル寸法には、その両方が各辺に加算されます。

左右・上下の外枠幅と隙間を0より大きく設定し、接続タブを有効にします。タブ幅、各辺のタブ数、外枠に接続する辺、隣接基板どうしの接続を設定できます。基板間をタブで接続する場合は、横・縦の基板間隔も0より大きくしてください。

タブのミシン目は初期状態で有効です。両端の接続部分に、穴径0.5 mm、ピッチ1.0 mmの非めっき穴（NPTH）を配置します。穴径とピッチは変更できます。EAGLEでは`plain`の穴、KiCadではラベルを非表示にしたNPTHフットプリントを出力します。ミシン目を無効にすると、穴のないタブになります。

外枠からのタブは、タブ幅全体とミシン目の穴が収まる、外枠から見える直線部分だけに配置します。正方形・長方形でない基板も同じ条件で扱います。元の円弧・円と直線の区別を保持し、加工用の近似線分を直線の辺とは誤認しません。丸い部分・角をまたぐ位置・短すぎる直線部分には、無理にタブや穴を設置しません。同一基板の複数行・複数列配置でも異種面付けでも、基板間タブは同じ条件で判定します。向かい合う両方の基板の直線部分が重なり、タブ全幅と穴が収まる区間だけを接続します。片側でも円弧・曲線になっている位置や、直線部分が短すぎる位置は、接続タブとミシン目を生成しません。外枠タブを意図的に省略した異形基板は、外枠未接続を理由に出力エラーにしません。

加工線は外枠・基板・タブの材料領域を合成してから、Dimension 20または`Edge.Cuts`に出力します。元の基板の穴は維持します。外形は閉じている必要があります。隙間やタブの加工線を作る際、円弧は最大偏差0.005 mmの折れ線で近似します。プレビューの色付き点線は各基板の外形、実線は材料とタブの周囲の加工線です。

画面とエラーメッセージは英語・日本語・ドイツ語に対応します。OSの優先言語リストから最初に対応する言語を使用し、de-DE・de-AT・de-CHなどの地域別ドイツ語にも対応します。対応言語がない場合は英語で表示します。アプリ内の言語切り替え設定はありません。

外枠がある場合、パネル外側の角は初期設定でR2 mmです。角のRを0にすると直角になります。Rはパネル幅・高さの半分を上限とし、角の曲線も最大偏差0.005 mmで近似します。パネル全体の外接寸法は変わりません。

## 元のシルク表記の維持

複製した部品の内部識別子は重複を避けますが、表示される部品番号は元の表記を維持します。

KiCadでは複製側の参照フィールドを非表示にし、同じ位置・回転・レイヤー・文字設定で通常のフットプリント文字を追加します。フットプリント文字中の`${REFERENCE}`も元の値に固定します。元から非表示だったラベルは表示しません。

EAGLEでは移動済み・スマッシュ済みのNAME属性を通常の固定文字に変換し、表示設定と座標を維持します。部品と接続先の内部参照は整合性を保って変更します。パッケージのNAME・VALUEラベルは、所属するライブラリごとに解決します。

以前に生成したパネルへこの動作を適用する場合は、元の基板から再度書き出してください。

## 異種面付け

複数ファイルをまとめてドロップするか、既存のリストに追加すると、すべての基板を1枚のパネルに配置します。1回のドロップは読み込み前にまとめ、ドラッグ＆ドロップで受け取った順序を保持するため、非同期のファイル取得で配置順が変わることはありません。

同じパスのファイルは重複して追加しません。読み込めないファイルは名前と理由を表示し、正常に読み込めた基板はそのまま利用できます。各ファイルを1枚ずつ配置し、列数で折り返します。行数は自動計算し、行の高さはその行で最も高い基板に合わせます。1ファイルだけの場合は、行数×列数による複製です。

| 入力 | 出力 | 必要環境 |
| --- | --- | --- |
| EAGLEのみ | 1つの`.brd` | アプリ内で処理 |
| KiCadのみ | 1つの`.kicad_pcb` | アプリ内で処理 |
| EAGLEとKiCadの混在 | 1つの`.kicad_pcb` | KiCad 10以降のインストール |

混在時は、インストール済みKiCadの`pcb import`コマンドでEAGLE基板を変換してから統合します。`/Applications/KiCad/KiCad.app`、`/Applications/KiCad.app`、`~/Applications`内の同じ構成のパス、標準的なHomebrewのCLI配置先を検索します。一時ディレクトリで変換し、読み込み後に削除します。変換コマンドを利用できない場合は、KiCad 10以降をインストールしてください。

変換前に、一時コピー内のEAGLEのplainにあるtRestrict（41）・bRestrict（42）・vRestrict（43）の矩形を、同じ形のポリゴンへ変換します。KiCad 10がこれらの矩形を`UNDEFINED`レイヤーのzoneとして取り込む問題を回避し、矩形の範囲・回転、表裏の銅箔禁止・ビア禁止の設定を保持します。元の基板ファイルは変更しません。EAGLEパネルの完成プレビューにも適用されます。

EAGLE出力の数値は指数表記を使わない小数に統一します。これにより、0付近の丸め誤差をKiCadが指数表記として正しく読み取れず、穴などの形状がずれる問題を防ぎます。旧版が出力したEAGLEファイルも、変換前に一時コピー内の形状属性の数値表記を正規化します。

部品、ネット、UUID、EAGLEライブラリは基板ごとに識別子を分け、シルク表記は元のまま維持します。KiCadのグループ内参照は基板全体で整合するよう変更します。ネット番号を使う形式と、ネット名を使う形式の両方に対応します。EAGLEのネットクラスは上限16クラスの範囲で保持します。

パネル共通の設定（積層・基板厚など）は、混在時はリスト内で最初のKiCad基板、同じ形式だけの場合は最初の基板から取得します。銅箔の層数と順序はすべての基板で一致する必要があります。

EAGLE変換後とパネル出力前にレイヤー参照を整理します。変換された参照・値フィールドのレイヤーが未定義の場合は、対応する面のシルク・製造用レイヤーを補います。それ以外の未割り当ての注記はコメントレイヤーに保持し、文字・位置・表示状態を維持します。レイヤーの表示名を正式名へ揃え、必要な標準レイヤー定義を補い、設定や基板要素より前に定義を配置します。銅箔などの電気的な要素でレイヤーが不明な場合は、勝手に別の銅箔層へ割り当てず、要素の種類を示すエラーを表示します。

異種面付けの加工線には、配置した各基板の実際の外形を使用します。タブは途中に別の基板がない隣接基板または外枠に接続し、タブ幅が収まらない短い区間は使用しません。タブ有効時に、正方形・長方形の基板が外枠へ繋がらない場合は、出力時に設定変更を案内します。パネル全体を横切る分割ガイド線は、他の基板を横切らない位置にだけ生成します。外枠とミシン目の設定はパネル全体に適用します。

## 完成プレビュー

配置プレビューの下にある **完成プレビューを開く** を押すと、サイズを変更できる別ウィンドウで、部品実装前のパネルをSVG表示します。緑のソルダーマスク、マスクで覆われた配線、金色の露出銅箔、白いシルク、加工溝、タブ、ドリル穴を表示します。

| 操作 | 操作方法 |
| --- | --- |
| 表示面の切り替え | 表面、または裏から見た裏面を選択します。 |
| 拡大・縮小 | プレビュー領域でトラックパッドの2本指を広げる・つまむ操作、または拡大・縮小ボタンを使います。倍率は25〜800%です。 |
| 倍率の確認 | ツールバーの倍率表示は、ピンチ操作と拡大・縮小ボタンに同期します。 |
| パネル全体を表示 | **全体表示** を押すと、パネル全体が収まる100%表示に戻ります。 |
| 拡大した表示の移動 | プレビュー領域をスクロールします。 |
| 表示面の保存 | **PNG保存** を押すと、透過PNG画像を書き出します。 |

ピンチ操作はスクロール可能な範囲で指の位置を基準に拡大縮小します。表裏を切り替えても倍率を維持します。画面の文字サイズは、メインウィンドウの **文字サイズ** またはアプリの「設定」から調整してください。完成プレビューには個別の文字サイズ調整ボタンはありません。

PNGにはズーム率に関係なくパネル全体を保存します。標準は300 dpi相当で、大きなパネルは縦横各8,192画素以内・総画素数16,777,216以内に縮小します。

詳細画像はボタンを押した時だけバックグラウンドで生成します。各ウィンドウの表示内容は生成時点の設定です。配置変更後は元画面のボタンから再生成してください。編集中も通常の配置プレビューを利用できます。単一基板の行列複製も含め、詳細表示と書き出しで共通の加工形状を使用し、外形線の重複を防いでいます。

完成プレビューには、入力形式にかかわらずインストール済みの **KiCad 10以降** が必要です。実際の出力用面付け基板を生成し、必要に応じてEAGLEインポーターで変換してから、KiCadのSVG出力機能で銅箔・マスク開口・シルクを描画します。レイヤー座標と文字のストローク形状を維持し、基板外形とドリル穴を合成します。

内部のSVGには色、マスク、形状を含みます。保存したPNGも外観と穴の透過を維持し、外部画像に依存せず単独で利用できます。元ファイルは変更せず、一時的な描画ファイルは生成後に削除します。

## 入出力検証と閾値

`PanelLimits`では、符号付き座標（mm）、寸法（mm）、配置数、生成穴数、パーサーの深さ、ファイルサイズを別々の閾値として管理します。数値計算・資源消費を制限する値と、製造条件は区別します。関数の境界で入力値と戻り値を確認し、有限値、閉じた外形、穴の配置、生成データ、出力外形と報告寸法の一致を検証します。ソースコードのコメントには関数の役割、変数の単位・有効範囲、検証理由を英語（EN）・日本語（JA）・ドイツ語（DE）で併記します。コメントはソース上で3言語を読める形式で、OSのロケールによる切り替えは行いません。MITライセンスの正式な原文、SPDX識別子、ツール用の指示行は保持します。制御構文の波括弧は省略しません。

回帰チェックには4層・6層のEAGLE/KiCad、内層配線の保持、銅箔の層数・順序が異なる基板の拒否を含みます。`--samples`指定時は、インストール済みKiCadのインポーターを使った混在チェックも実行します。
